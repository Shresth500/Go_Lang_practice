## Arrays
- Collection of similar data types stores at contingous memory location

- fixed length
- contains properties like length and capacity
- for array length and capacity is same


Syntax: 
```
// Declare an array of integers with a fixed size of 5
var <array_name> [<size_of_the_array>] <data_type>

// Declaring and Initializing array of integer
var <array_name> [<size_of_the_array>] <data_type> = [<size_of_the_array>] <data_type> {
    // list of data
}

// Another way to initialize the data
<array_name> := [...]<data_type>{// list of data}
```
